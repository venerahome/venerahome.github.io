# Блог Венеры

На сайте ДВА ОТДЕЛЬНЫХ блога: «Блог о Греции» (`/blog/greece/`) и «Блог о Болгарии» (`/blog/bulgaria/`), на 4 языках (`/blog/<язык>/greece/` и т.д.); `/blog/` — страница выбора блога. Статьи не смешиваются: в каждом блоге — только статьи о своей стране, «Читайте также» — тоже только из своего блога. Адреса самих статей не меняются: `/blog/<slug>/`.

Каждая статья — один файл `blog/posts/ГГГГ-ММ-ДД-slug.json`. После добавления запустить `python3 blog/build_blog.py` — он соберёт блог на 4 языках (`/blog/` RU, `/blog/bg/`, `/blog/en/`, `/blog/de/`), страницы статей, RSS-ленты, карту сайта и фирменные картинки для соцсетей `blog/og/<slug>-<язык>.jpg` (рисуются один раз; `--og` — перерисовать все).

Обложки статей НЕ фото: блог сам рисует фирменную карточку — рубрика, главная цифра статьи, подпись к ней, фото и имя Венеры. Поэтому у каждой статьи должна быть сильная главная цифра (`stat`).

## Формат статьи

```json
{
  "slug": "latinicey-cherez-defis",
  "date": "2026-10-22",
  "category": "greece",                // greece | bulgaria (europe — только старые статьи)
  "blog": "greece",                     // в каком блоге статья: greece | bulgaria (по умолчанию — по категории)
  "cta": "golden-visa",                 // golden-visa (Греция/Европа) | contact (Болгария)
  "status": "published",
  "stat": {                             // главная цифра статьи для обложки
    "value": {"ru": "+14,8%", "bg": "+14,8%", "en": "+14.8%", "de": "+14,8 %"},
    "label": {"ru": "рост цен на жильё в Болгарии за год", "bg": "…", "en": "…", "de": "…"}
  },
  "ru": {"title": "…", "excerpt": "1–2 предложения", "tldr": ["вывод 1", "вывод 2", "вывод 3"], "body": "текст в мини-разметке"},
  "bg": {…}, "en": {…}, "de": {…},     // испанский (es) с 04.11.2026 не нужен
  "sources": [{"title": "Издание — заголовок", "url": "https://…"}]
}
```

- `stat.value` — коротко (до ~10 знаков): «+14,8%», «3% → 15%», «€400 000», «5 лет». Подпись — до 8 слов.
- `tldr` — ровно 3 коротких вывода «Коротко» (по одному предложению).
- Мини-разметка в `body`: `## Заголовок`, `### Подзаголовок`, пустая строка между абзацами, `- пункт`, `1. пункт`, `> цитата`, `**жирный**`, `[текст](https://ссылка)`.
- Если какого-то языка нет, страница этого языка покажет английский текст — но статья должна быть на всех 4 языках (ru, bg, en, de).

## Правила статей (стиль Венеры)

- Опора на реальную свежую новость или проверенный факт, с источниками в конце. Цифры — только из источников.
- Своими словами: без копирования абзацев, цитата максимум одна и короче 15 слов.
- Тон: личный и лёгкий, от первого лица («я»), как будто Венера рассказывает знакомому — без канцелярита. Мнение и советы — да, выдуманный личный опыт — нет.
- Не трогать политику и не задевать болгар и греков — «это чудесные страны».
- Длина 500–800 слов, 3–5 подзаголовков, вывод «что это значит для покупателя».
- Чередовать блоги: Греция / Болгария (одна статья — одна страна, темы не смешивать; общеевропейскую новость подавать только глазами одной страны и ставить в её блог); новости / законы и налоги / цены / жизнь и переезд / Golden Visa.
- Переводы (bg, en, de) — тот же смысл, естественный язык, местные форматы чисел. Имя в латинице: Venera Khassanova.
