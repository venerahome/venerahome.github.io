# Блог VENI

Каждая статья — один файл `blog/posts/ГГГГ-ММ-ДД-slug.json`. После добавления запустить `python3 blog/build_blog.py` — он соберёт страницы `/blog/`, `/blog/en/`, страницы статей и RSS-ленты `/blog/rss.xml`, `/blog/en/rss.xml`.

## Формат статьи

```json
{
  "slug": "latinicey-cherez-defis",
  "date": "2026-10-22",
  "category": "greece",            // greece | bulgaria | europe
  "image": "https://…jpg",          // обложка 3:2, с сайта (фото объектов) — без чужих логотипов и текста
  "cta": "golden-visa",             // golden-visa (Греция/Европа) | contact (Болгария, общее)
  "status": "published",            // published | draft (draft на сайт не попадает)
  "ru": {"title": "…", "excerpt": "1–2 предложения", "body": "текст в мини-разметке"},
  "en": {"title": "…", "excerpt": "…", "body": "…"},
  "sources": [{"title": "Издание — заголовок", "url": "https://…"}]
}
```

Мини-разметка в `body`: `## Заголовок`, `### Подзаголовок`, пустая строка между абзацами, `- пункт`, `1. пункт`, `> цитата`, `**жирный**`, `[текст](https://ссылка)`.

## Правила статей (стиль Венеры)

- Опора на реальную свежую новость или проверенный факт, с источниками в конце. Цифры — только из источников.
- Своими словами: без копирования абзацев, цитата максимум одна и короче 15 слов.
- Тон: личный и лёгкий, от первого лица («я»), как будто Венера рассказывает знакомому — без канцелярита. Можно эмоции.
- Не трогать политику и не задевать болгар и греков — «это чудесные страны».
- Длина 500–800 слов, 3–5 подзаголовков, вывод «что это значит для покупателя».
- Чередовать: Греция / Болгария / Европа; новости / законы и налоги / цены / жизнь и переезд / Golden Visa.
- Английская версия — тот же смысл, естественный английский.
